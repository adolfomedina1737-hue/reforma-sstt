# Reforma SSTT

Sistema de Gestión de Reformas del Edificio SSTT.

## Características

- Gestión de unidades por plantas
- Registro de reformas y cambios
- PWA instalable
- Funciona sin conexión

## Plantas

- **Planta P**: P001 - P022
- **Planta 0**: 001 - 050
- **Planta 1**: 101 - 143
- **Planta 2**: 201 - 243
- **Planta 3**: 301 - 316 + 301A, 316A

## Instalación

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. O despliega en Vercel/GitHub Pages

## Tecnologías

- HTML5
- Tailwind CSS
- PWA (Service Worker + Manifest)
